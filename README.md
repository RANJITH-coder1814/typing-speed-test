# typing-speed-test
A simple Typing Speed Test Web Application built with HTML, CSS, and JavaScript. It allows users to test their typing speed and accuracy by typing a given paragraph within a limited time.
# ⌨️ Typing Speed Test

A simple web application to test your typing speed using HTML, CSS, and JavaScript.

## Features
- 60 second typing test
- Calculates Words Per Minute (WPM)
- Tracks typing mistakes
- Restart test option

## Technologies
- HTML
- CSS
- JavaScript

## How to Run
1. Clone the repository
2. Open index.html in your browser
